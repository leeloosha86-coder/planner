# Сервер «Моего планировщика»

Express + SQLite. Имя и телефон не запрашиваются и не сохраняются. Задачи, привычки, заметки, опыт и уровень привязаны только к Telegram ID.

## Запуск

1. Создайте бота через BotFather и получите токен.
2. Разместите этот каталог на Node.js-сервере с постоянным диском и HTTPS.
3. Скопируйте `.env.example` в `.env` и заполните значения. `PUBLIC_URL` — адрес сервера, `MINI_APP_URL` — HTTPS-адрес экспортированного интерфейса.
4. Выполните `npm install` и `npm start`. При запуске сервер сам установит webhook, команду /start и кнопку меню для открытия приложения.
5. Для интерфейса задайте `EXPO_PUBLIC_API_URL=https://адрес-сервера` и `EXPO_PUBLIC_BOT_USERNAME=имя_бота`, затем повторите экспорт Expo.

## Безопасность и синхронизация

- `GET /api/state` и `PUT /api/state` принимают только заголовок `X-Telegram-Init-Data` с действительной HMAC-подписью и свежим `auth_date`.
- Ключ проверки получается как `HMAC_SHA256("WebAppData", BOT_TOKEN)`; сравнение хешей выполняется безопасным `timingSafeEqual`.
- `ALLOW_INSECURE_DEV=true` разрешает локальный вход по `X-Dev-User-Id`. В публичной версии эта настройка должна быть `false`.
- SQLite хранит отдельные записи задач, привычек и заметок; транзакция не допускает частичного сохранения.

## Напоминания

Webhook отмечает пользователя после /start. Каждую минуту планировщик проверяет локальное время пользователя, повторы и выполнение задачи. Отправка одного напоминания фиксируется, поэтому дублей нет. Ответ Telegram 403 помечает бота заблокированным и останавливает дальнейшие попытки.
